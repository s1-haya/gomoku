# Gomoku
Developing a Gomoku AI using **Minimax, alpha-beta pruning, and heuristic evaluation**.

## Getting Started

### 1. Create a virtual environment

```bash
python3 -m venv venv
```

### 2. Activate the virtual environment

**Linux / macOS**

```bash
source venv/bin/activate
```

**Windows (PowerShell)**

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
make install
```

or

```bash
pip install -r requirements.txt
```

### 4. Run unit tests
```bash
make test
```

or

```bash
python3 -m unittest discover -s tests -v
```
